# Phase 3 Card Rulings — Brobnar, Mars, Sanctum, Untamed

One entry per new-house card. Canonical text and errata are in Code/PHASE_3_CARD_POOL.md; this file adds the official KeyForge Master Rulebook v18.3 FAQ rulings that bear on implementation, quoted as test cases where a card has a specific one. A card with no MRB 18.3 FAQ entry gets a one-line placeholder -- standard rules apply and no card-specific ruling exists to test against.

## Brobnar

### 001 Anger

**Rulings (MRB 18.3 FAQ):**
- If a card (such as Anger) allows you to use a creature and that creature is stunned, resolving it removes the stun instead of doing anything else.
- Using an exhausted creature (e.g. Bumpsy) with no legal fight target: the creature is readied by Anger's effect, but since it cannot be used to fight, it remains ready and the ability otherwise does nothing.

### 027 The Warchest

**Rulings (MRB 18.3 FAQ):**
- The Warchest only counts creatures destroyed in an actual fight (the power-for-power exchange during the fight step) -- a creature destroyed by "before fight" damage such as assault (e.g. Ancient Bear) does not count, even though it happened while a fight was being resolved.

### 037 Kelifi Dragon

**Rulings (MRB 18.3 FAQ):**
- Kelifi Dragon's play restriction ("cannot be played unless you have 7Æ or more") only checks when it is *played*. An effect that *puts* Kelifi Dragon into play directly (e.g. returned from a purge by an artifact leaving play) bypasses the restriction entirely, regardless of Æmber in the controller's pool.

### 038 King of the Crag

**Rulings (MRB 18.3 FAQ):**
- A 0-power creature with 0 damage on it is still destroyed (power-0/damage-0 satisfies "damage ≥ power").
- King of the Crag's power reduction is a continuous constant effect, so it can reduce an entering Brobnar creature to 0 power and destroy it before that creature's own "after it enters play" triggered ability gets a chance to resolve (e.g. against Pingle Who Annoys).

### 051 Phoenix Heart

**Rulings (MRB 18.3 FAQ):**
- Phoenix Heart's granted "Destroyed:" ability resolves in the order written: the host creature returns to its owner's hand *first*, then damage is dealt to "each creature still in play" -- so the returned creature (already out of play) is not among the creatures damaged by its own trigger.
- An upgrade-granted ability that refers to the upgrade by name (e.g. Armageddon Cloak's self-reference) refers only to that specific copy of the upgrade, not other copies of the same card.

### 255 Raiding Knight

**Rulings (MRB 18.3 FAQ):**
- Canonical worked example for the armor pipeline: attacking a creature with a Shadow-Self-style neighbor, armor first absorbs part of the pending damage at the original target, *then* the remaining (post-armor) damage is what gets redirected to the neighbor -- the attacker still takes full damage back from the original target's power as normal (Milestone C.1/C.2 ordering).

### 256 Sanctum Guardian

**Rulings (MRB 18.3 FAQ):**
- A "move a creature" effect never requires an actual change of position -- the creature may end up back where it started.
- A swap/move-within-battleline effect used on an opponent's creature "as if you controlled it" (e.g. via Replicator) does nothing: a creature cannot cross from one player's battleline to the other's except through an effect that explicitly changes control (Milestone C.12).

### 257 Sequis

**Rulings (MRB 18.3 FAQ):**
- When a reap/fight ability is used "as if you controlled" an opponent's creature (Replicator-style), Sequis's capture still follows the default capture rule relative to the temporary controller -- it captures from the true opponent's pool. No special-casing needed beyond the existing "use as if yours" framework.

### 263 Armageddon Cloak

**Rulings (MRB 18.3 FAQ):**
- The granted "Destroyed:" ability is a replacement effect (an `InsteadEffect`): when the host creature would be destroyed, destroy Armageddon Cloak and fully heal the creature instead, so the creature is never actually destroyed.
- It can absorb multiple simultaneous destruction sources in the same batch: if two separate effects tag the host for destruction at the same time, resolving Armageddon Cloak's replacement (removing the destroy tag from the creature) before the other pending destruction is processed protects against both waves, since the active player chooses the order of simultaneous resolutions (Milestone C.11).

### 327 Lost in the Woods

**Rulings (MRB 18.3 FAQ):**
- "Choose 2 friendly creatures and 2 enemy creatures" resolves as much as it can independently per side (MRB "Resolve As Much As You Can", p.20): if one side has fewer than 2 legal creatures (including zero), you simply choose fewer or none from that side instead of the whole effect failing.

### 328 Mimicry

**Rulings (MRB 18.3 FAQ):**
- While resolving as a copy of another card, Mimicry takes on that card's name, house, text and keywords for the purposes of that resolution -- including being considered to belong to the copied card's house for any house-matching effect (Milestone C.15's dynamic `CardDef` substitution).
- Deckbuilding-only rulings (which deck-list slot the copy counts against, Alpha- and Enhance-keyword interactions) do not apply: CotA has no Alpha or Enhance keyword and this engine does not model post-play deck-list legality, so only the in-game copy substitution is in scope.
